# One-time Android bootstrap (important)

The full `android` configuration is provided, but the Gradle wrapper JAR and operating-system-specific wrapper scripts are generated by Flutter and cannot be manufactured here without the Flutter SDK. Perform these steps with Flutter installed.

**On Windows PowerShell (inside the extracted `Karya_2.0_Flutter` folder):**

```powershell
flutter doctor
flutter create --platforms android --project-name karya_app --no-pub --no-overwrite .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

If your Flutter version does not recognize `--no-overwrite`, omit it (Flutter skips files it already has by default). If wrappers remain missing, use a temporary project:

```powershell
cd ..
flutter create --platforms android --project-name karya_app temp_karya_scaffold
Copy-Item temp_karya_scaffold\android\gradlew* Karya_2.0_Flutter\android\
Copy-Item temp_karya_scaffold\android\gradle\wrapper\gradle-wrapper.jar Karya_2.0_Flutter\android\gradle\wrapper\
cd Karya_2.0_Flutter
flutter pub get
```

Do not overwrite `android/app/build.gradle.kts`, `AndroidManifest.xml` or application icons with scaffold defaults. The provisional package ID must be confirmed with the publisher before the first store upload.

## More automated options

Once Flutter and Android Studio are installed, run `powershell -ExecutionPolicy Bypass -File .\tool\BUILD_KARYA_WINDOWS.ps1` from the extracted project folder. It creates missing Android wrapper files, resolves dependencies, formats, analyzes, runs unit/widget tests and attempts a debug APK build. It stops if a step fails, instead of calling a broken build a success.

Optional GitHub Actions workflow: `.github/workflows/android-build.yml`. Push the project to a private or public GitHub repository you control, then open Actions → Kārya Android build and tests → Run workflow. Once green, download the `Karya_2.0_Test_APK` artifact. This was authored but **not run here** and must be debugged if CI finds build errors. No keystore is uploaded to Actions.
